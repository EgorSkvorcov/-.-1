Блоки элементов создаются с помощью следующих элементов:
"div" - он используется для группировки элементови создания структуры страницы;
"nav" - используется для навигации на странице, содержит ссылки;
"aside" - используется для какой-то косвенной информации, для блока рекламы, боковой панели;
"footer" - содержит информацию о странице (авторские права, ссылки на политику конфиденциальности);
"section" - для заголовков.
